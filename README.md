# Тренажёр 112

Учебное приложение с FastAPI backend и React/Next.js интерфейсом. Основной сценарий ДДС: преподаватель готовит и утверждает билеты, назначает занятие, курсант последовательно обрабатывает карточки, преподаватель разбирает сохранённые действия и выставляет экспертную оценку. Самостоятельная тренировка курсанта доступна отдельно.

Код также содержит операторский тренажёр, ASR, интеграционные адаптеры и несколько поколений аналитики. Их наличие не означает готовность внешних сервисов. Речь и нейроотчёты требуют подготовленных моделей и сервисов; реальные SIP/SPO112 остаются отдельной интеграционной приёмкой.

## Запуск для разработки

Базовая среда: Python3.11/Linux x86_64 и Node22 (не ниже22.12). Runtime закреплён полным hash lock; frontend использует npm/package-lock.

```bash
python3.11 -m venv .venv
. .venv/bin/activate
python -m pip install --require-hashes -r requirements.lock
python -m scripts.setup_env --init
bash run.sh
```

Инициализатор создаёт новый приватный `.env` с уникальными секретами и отказывается перезаписывать существующий. Пароли находятся только в этом файле; не добавляйте его в Git.

В другом терминале:

```bash
cd frontend_react
npm ci --ignore-scripts
npm run dev
```

Интерфейс: http://localhost:3000; API: http://localhost:8000/docs. Next dev проксирует API в backend. Локальная БД без явного DATABASE_URL находится в `data/112_simulator.db`; ранее существовавший корневой файл поддерживается до его переноса, чтобы не создавать вместо него пустую БД. Начальный ADMIN создаётся startup приложения.

## Что находится в папках

`backend` — сервер; `frontend_react` — интерфейс; `scripts` — утилиты; `docs` — текущая документация и отдельная история; `data` — БД, uploads и рабочие результаты; `models` — внешние модели; `assets` — поставляемое статическое аудио; `docker` — инфраструктурные ресурсы. Нативные ASR bindings сгруппированы в `backend/native/asr`, а runtime libraries — в `backend/bin`.
