# Документация: где искать действующие сведения

Актуальные точки входа: [README](../README.md), [карта кода](../PROJECT_STRUCTURE.md), [развёртывание](../DOCKER.md), [восстановление](../RECOVERY.md), [проверки](testing.md). [Аудит](audit/2026-10-19/REPORT.md) описывает исходный снимок до исправлений; [исполнение](audit/2026-10-19/IMPLEMENTATION.md) — итог ветки. Исходный построчный [реестр всех документов](audit/2026-10-19/documents.md) сохраняется как свидетельство.

| Документы | Как использовать |
|---|---|
| `admin-access-restrictions.md` | Действующий контракт ADMIN: административная роль отдельно от учебной |
| `dds-sequential-workflow.md`, `dds-phone-training.md` | Действующий порядок очереди/телефонного упражнения; приоритет над ранним описанием single-card DDS |
| `dds-report-data.md`, `dds-report-jobs.md`, `dds-report-teacher-ui.md`, `dds-qwen-runtime.md` | Контракты сохранённых фактов/нейроотчёта; адреса runtime и запуск сверять с DOCKER.md |
| `dds-lesson-cycle.md`, `dds-lesson-cycle-ui.md` | Ранние этапы реализации. Для завершения карточки требуется dispatch; общий finish проверяет всю очередь. Не использовать ранние single-card инструкции как текущий acceptance |
| `architecture/*.md` | Исторический дизайн. Ссылки на `v2_engine`, прежние API и численные гарантии не описывают действующее приложение. Фактическая карта вынесена в PROJECT_STRUCTURE.md |
| `*-worker-brief.md`, `admin-integrity-review*.md`, `backlog_features.md`, `migration_agent_prompt.md`, корневой `MIGRATION_LOG.md` | История поручений/планов, не runbook и не доказательство готовности |
| `project-context/*.md`, `project-context/tasks/*`, `project-context/sources/*` | Исходные требования, решения, handoff и исторические задания. Пути сохранены для трассировки. Выполнение подтверждается кодом и проверкой, не галочкой в задании |
| `archive/one-off-scripts/*` | Невыполняемые копии одноразовых патчей. Возвращать только после анализа исходной версии и отдельной проверки |

Функции разных поколений (operator runtime, локальное демо, три формата билетов) не объявлены лишними без миграции потребителей. Кандидаты на удаление, уверенность и условия перечислены в аудите. Все предыдущие отчёты/brief относятся к своему снимку; фактические ограничения этой ветки описаны в IMPLEMENTATION.md.
