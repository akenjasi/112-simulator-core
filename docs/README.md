## Статус материалов

Действующие описания находятся в таблице выше. При изменении поведения обновляйте основной документ по теме. Результаты отдельных задач фиксируйте в коммите; существенные свидетельства сохраняйте отдельно от инструкций.

- [Аудит и его доказательства](history/audits/2026-10-19/REPORT.md) — сохранённый снимок до/после исправлений, не новые задания.
- [История](history/README.md) — датированные решения и результаты прежних проверок. Это не инструкции текущему исполнителю и не подтверждение состояния новой версии.
- [Источники](sources/README.md) — исходные материалы и границы их применимости. Требование не означает реализацию.
- `dds-workflow-frontend-baseline.json` — машинный baseline независимого scope guard. Путь и содержимое сохраняются; это не обычная документация.
- `ui-review/` — исторические иллюстрации к замечаниям; ссылки собраны в истории.

Локальные игнорируемые `project-context`, handoff и заметки из других checkout не являются общими действующими инструкциями. Не копируйте их в новую задачу автоматически. Уникальное требование сначала сверяйте с текущим поручением и кодом, затем внесите необходимое уточнение в основной документ или backlog.
