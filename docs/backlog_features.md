# Бэклог фич на будущее (Развитие MVP)

В данном документе собраны концепции и фичи, которые будут реализованы после завершения базового MVP симулятора (когда будет готово ядро: создание урока -> рабочее место -> базовая оценка).

## 1. Асинхронные учебные модули (Домашние задания)
- **Для преподавателя:** Возможность сформировать пакет билетов (например, 15 билетов по теме "ДТП с пострадавшими") и назначить его конкретной учебной группе или всем студентам со статусом "Самообучение / ДЗ".
- **Для курсанта:** В личном кабинете появляется раздел "Назначенные модули", которые можно проходить в удобное время, без привязки к Live-сессиям преподавателя.

## 2. Тренировочный режим "Работа над ошибками"
- Кнопка в профиле курсанта, которая "на лету" собирает тренировочный модуль исключительно из тех категорий билетов, где курсант ранее допускал фатальные ошибки. 
- Направлено на точечную прокачку слабых мест без участия преподавателя.

## 3. Ночная генерация ИИ-рекомендаций (AI Daily Report)
- **Проблема:** Обращение к LLM (ИИ) для генерации развернутого текстового фидбека по каждому билету в реальном времени создает непредсказуемую и высокую нагрузку на сервер во время занятий.
- **Решение:** 
  - Первичная (базовая) оценка билета происходит мгновенно по эталонным правилам (совпадение адреса, служб).
  - Глубокая аналитика и генерация текстовых "Рекомендаций от ИИ" запускается как фоновая задача (cron) в период минимальной нагрузки (ночью).
  - ИИ агрегирует всю активность студента за прошедший день, анализирует паттерны ошибок и формирует единый отчет-наставление на следующий день (например: *"Вчера ты отлично справлялся с Пожарами, но в 3 из 4 случаев с Газом забыл уточнить номер квартиры"*).
  - Это масштабируемый и дешевый по ресурсам подход.
