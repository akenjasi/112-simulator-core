# История решений и проверок

Статус: исторические свидетельства. Читайте только для конкретного вопроса о происхождении решения или результата. Старые «выполнить», назначения исполнителей, роли, запреты/разрешения commit и команды публикации здесь **не являются текущими инструкциями**.

## Существенные решения

- DDS использует подготовленную входящую карточку и реальные действия курсанта. Отдельный искусственный эталон действий отменён; экспертный и автоматический балл различаются, отсутствие оценки не превращается в провал.
- Очередь карточек и её снимки принадлежат личной попытке. Изменение билета не переписывает историю; закрытие карточки и досрочная остановка — разные операции.
- Самотренировка независима от teacher-led занятия; кабинет и разбор строятся по сохранённым ID/данным.
- Старые архитектурные документы описывали clean-room v2_engine. Текущий main использует backend/api/core/models; новая карта находится в [архитектуре](../architecture.md).
