# Источники и прежние требования

Эта папка не задаёт агенту роль или полномочия и не подтверждает реализацию функции.

- `112_Simulator_Technical_Documentation.docx` перенесён из корня docs без изменения байтов. Это прежний технический документ проекта; его актуальность и нормативный статус не подтверждены. Текущую систему описывают [архитектура](../architecture.md) и [продуктовые документы](../README.md).
- [Границы старого проектного замысла](legacy-scope.md) сохраняют темы требований, которые нельзя считать реализованными по старым заданиям.

114 файлов прежнего prompts были поручениями исполнителям clean-room/migration/UI этапов. Приложение не читало их как runtime prompts; единственная найденная операция доставки всего каталога — offline packaging — убрана. Runtime запросы модели формируются в Python-модулях factoids_llm/dds_report_llm/ai_worker. Старые per-worker роли и команды не нужны в текущем дереве; точные версии доступны через Git baseline, указанный в [истории](../history/README.md).

Локальные `docs/project-context` в другом checkout исключены из Git локальным info/exclude. Эта уборка не удаляет их, не копирует их содержимое в новый main и не делает прежние разрешения общими. Уникальные исходные требования пользователя нельзя удалять без сохранённого оригинала; согласованные изменения отражаются в основных документах/backlog.
