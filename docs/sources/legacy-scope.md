# Границы прежнего проектного замысла

Статус: историческая справка по содержанию старых architecture/prompts, не действующая спецификация API. Оригиналы находятся в main `3f8f543` и его истории. Она не заменяет исходное ТЗ заказчика.

| Тема старых материалов | Как читать сейчас |
|---|---|
| Clean-room v2_engine, архитектор-only, builder workers, «ждать брифа» | Схема организации прежней миграции; не текущая структура кода и не роль нового агента |
| Разделение пользователей/групп, сценариев, runtime, оценки, знаний | Полезная карта предметных областей. Реальные поля/JSON/связи определяют backend/models и schemas, а не старые копии контрактов |
| Автоклассификация служб, SLA, оценка коммуникации/карточки/времени | Исторические цели операторского сценария. Они не переносятся автоматически на DDS: отдельный искусственный эталон действий DDS отменён |
| PostgreSQL, TLS, шифрование, LDAP, MFA, резервирование, интеграции | Требования безопасности и эксплуатации, не доказательство полного соответствия. В текущем коде есть частичные реализации/исключения и ограничения из backlog |
| Домашние модули, работа над ошибками, ночные рекомендации | Идеи развития; перенесены в единый backlog, а не обещаны как готовые функции |
| Верстка/heatmap/radar/старые single-card routes и действия | Задания своего этапа. Некоторые явно отменены позже; применять старую верстку/действие по prompt нельзя |
| «Реальная телефония»/voicebot/ASR/TTS | Наличие адаптера или анимации не подтверждает внешний звонок/голос. Нужна отдельная приёмка с наблюдаемым результатом |

Действующие сценарии — в [карте документов](../README.md), незавершённые требования — в [backlog](../backlog.md). При возврате к старому требованию сначала согласуйте его применимость, затем обновляйте основной документ, не восстанавливайте пачку поручений агентам.
