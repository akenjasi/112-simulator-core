## Значение статусов билетов

- `DRAFT` — «Черновик»: ещё не готов к утверждению/использованию.
- `UNDER_REVIEW` — «На проверке»: преподаватель проверяет и утверждает сценарий.
- `APPROVED` — «Утверждён»: может назначаться при корректной карточке ДДС.
- `ARCHIVED` — «В архиве»: не назначается, история проведённых занятий сохраняется.
- `active` / `ACTIVE` — прежнее техническое значение. Сейчас показывается как «Не проверен» с возможностью ручного утверждения. Это не аналог «Утверждён» и не состояние запущенного урока.

Статус билета, состояние урока и результат попытки — три разных понятия; не объединять их в один список.
