# FIX-03 — убрать тепловую карту из аналитики

## Причина

Тепловая карта ошибок оператора 112 не подходит для текущего сценария ДДС. Тестер просит убрать этот раздел.

## Сделано

- Из `frontend_react/app/teacher/analytics/page.tsx` удалены раздел тепловой карты, его состояние, вспомогательные константы и запрос `errors-heatmap`.
- Остальные разделы аналитики сохранены: сводка, графики, сравнение групп, история и разбор ответов.
- Из существующих overview/navigation тестов удалены неиспользуемые ответы мока для тепловой карты.
- Новый `frontend_react/tests/27_teacher/03_tester_heatmap.test.tsx` проверяет вкладки «Графика и дашборды» и «Все разделы»: сводка и сравнение групп загружаются, тепловая карта отсутствует в DOM и запрос к её API не отправляется.

## Проверка

```sh
npm --prefix frontend_react test -- \
  tests/27_teacher/27_05_analytics_overview.test.tsx \
  tests/27_teacher/27_05_analytics.test.tsx \
  tests/27_teacher/analytics-detail-navigation.test.tsx \
  tests/27_teacher/03_tester_heatmap.test.tsx --maxWorkers=1
```

Результат: **4 файла, 15 тестов прошли**.

## Границы

Backend API тепловой карты сохранён для совместимости. Данные и схема БД не менялись. Интерфейс самого занятия ДДС в этом исправлении не затрагивался. Пересборка и перезапуск стенда не выполнялись.
