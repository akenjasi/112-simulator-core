# FIX-04 — утвердить все подходящие билеты

Исполнитель: Codex. Реализация завершена после команды пользователя.

В `frontend_react/app/teacher/tickets/page.tsx` реализован массовый обработчик;
есть `frontend_react/tests/27_teacher/27_02_bulk_approve.test.tsx`. Итоговые проверки
пройдены: пять тестов массового утверждения в составе общего набора 62 passed.
Стенд ещё не обновлялся. Новое чтение списка учитывает серверный статус повторно
отредактированного билета; подтверждённый статус защищается только от старых GET.

## Контракт

- Кнопка «Утвердить все» работает по текущему отфильтрованному списку; область явно подписана.
- Через существующий `POST /api/tickets/{id}/approve` обрабатываются только DRAFT/ACTIVE/UNDER_REVIEW;
  APPROVED/ARCHIVED/удалённые исключаются. Один ID отправляется один раз.
- Повторный bulk и индивидуальное утверждение блокируются до окончания операции.
- Видны прогресс, успехи и конкретные ошибки. При частичном отказе успешные изменения
  остаются; повтор касается только оставшихся неудачных билетов.
- Не обходить серверную проверку эталона, не менять генерацию и сохранённые билеты.

Проверки после команды: `27_02_bulk_approve.test.tsx`, `27_02_tickets.test.tsx`,
`group-ticket-review.test.tsx`, `npm run typecheck`, `git diff --check`.

Не запускать параллельно с изменениями генерации в том же frontend-файле (FIX-05).
