# FIX-06 — скрывать завершённые уроки

Исполнитель: Codex. Реализация завершена после команды пользователя.

В `frontend_react/app/teacher/analytics/page.tsx` реализованы checkbox
«Скрыть завершённые уроки», локальная настройка и фильтр по COMPLETED.
Проверены переключение, remount, ACTIVE/WAITING и экспорт текущего набора: два
новых теста прошли в составе общего набора 62 passed. Стенд ещё не обновлялся.

## Критерии

- Явное обратимое скрытие завершённых занятий; никаких DELETE/изменений статуса в БД.
- ACTIVE/WAITING не исчезают. После снятия флажка завершённые возвращаются.
- Поиск и фильтр группы продолжают работать совместно с настройкой.
- Настройка сохраняется в браузере, изначально выключена. Недоступный localStorage
  не должен ломать экран; смена настройки не сбрасывает открытый разбор ответа.
- Экспорт истории использует тот же видимый набор; экспорт конкретного разбора остаётся прежним.
- Не возвращать тепловую карту и не смешивать с FIX-08.
