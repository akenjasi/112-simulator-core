# FIX-08 — курсанты в журнале разбора / split-screen

Исполнитель: отдельный Gemini worker `fix08_split`. Только после команды пользователя.

## Подтверждённые факты

`teacher/analytics/page.tsx` начинает split с пустыми sessionId/cadets.
Сам экран предлагает ручной ID; `fetchSessionAnalytics` обращается к
`/api/v1/analytics/sessions/{id}`. Backend `get_session_analytics` ищет **ExamSession**,
а не групповое Assignment/lesson, и возвращает одного курсанта этой попытки.
В истории уже существует рабочий переход «Разобрать ответ» по record/card ID.
Подстановка ID урока в API попытки не является исправлением и даст 404.

## Работа и приёмка

- Дать на split-экране выбор доступного преподавателю урока и затем его курсантов/карточек.
  Для группового списка использовать lesson detail / сохранённые сессии, а не выдуманный общий session ID.
- Группа из двух курсантов видна без ручного знания UUID. Карточка выбранного курсанта
  открывается в имеющемся SplitScreen с правильным record/card/session ID.
- Сохраняются прямой переход из истории, индивидуальные назначения, несколько карточек
  в очереди и попытки без оценки. Не показывать выдуманный зачёт.
- После выбора другого урока/пустого ответа старые данные очищаются; поздний ответ
  предыдущего запроса не заменяет текущий. Понятные loading/empty/401/403/404/retry.
- Только свой урок: чужой преподаватель и чужой курсант не получают данные.

Scope: teacher/analytics, при необходимости узкий совместимый analytics/lesson endpoint,
существующий split-screen компонент только при необходимости. Не менять рабочее место ДДС.
Сохранить уже удалённую карту FIX-03, фильтр FIX-06 и исправленный Excel.
