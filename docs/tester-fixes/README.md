## Общий стартовый промпт для одного Gemini worker

Прочитай этот README и **только назначенный файл ТЗ**. Исправь один указанный пункт;
остальные задачи не входят в scope. Сначала воспроизведение и минимальный независимый
тест, затем изменение и проверка. Не читать целиком историю проекта и не раздавать
свои подзадачи новым агентам: бережём лимиты. Не запускать полный test suite на каждом шаге.

Работай по текущему dirty tree: не делать reset/checkout/clean, не затирать чужие правки,
не commit/push/deploy, не трогать живую БД, пароли и уже сохранённые попытки.
Тесты выполняются с синтетическими данными в отдельной временной БД.
Для Next.js сначала `frontend_react/AGENTS.md` и применимые локальные Next docs.

По завершении: конкретная причина, файлы, выполненные команды/результаты,
оставшиеся ограничения. Непроверенную гипотезу не называть установленной причиной.
Не считать mock-тест доказательством доступности реальной локальной модели.
