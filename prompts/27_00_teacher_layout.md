# Задача 27.0: Главная страница и Глобальный Layout (Teacher Workspace)

## Контекст и Целевая аудитория
Рабочее место преподавателя будет использоваться людьми в возрасте (60+). Мы провели UX-интервью и утвердили следующие принципы дизайна, которые **обязательны** для всех страниц:
1. **Крупный интерфейс:** Базовый шрифт 16-18px, увеличенные `padding` в таблицах и формах, большие кнопки.
2. **Высокая контрастность и Единый стиль:** Темно-серый или черный текст на белом фоне. **Запрещено** использовать светло-серый текст (`text-gray-400` или `text-muted-foreground`), который сливается с фоном. Цветовые решения (основной цвет, акценты, фоны) **строго брать** с уже существующих страниц АРМ Оператора-112 (`/operator`) и Тренажера ДДС (`/`), чтобы интерфейс преподавателя смотрелся гармонично и был частью единой экосистемы.
3. **Простая терминология:** Исключить англицизмы и сложные термины (никаких "Дашбордов", "Сессий", "Аналитики").
   - `/teacher/groups` -> "Ученики" (или "Группы")
   - `/teacher/sessions/new` -> "Начать урок"
   - `/teacher/tickets` -> "База билетов"
   - `/teacher/analytics` -> "Журнал оценок"
   - `/teacher/knowledge` -> "Справочник"

## Требования к UI

### 1. Глобальный Layout (Боковое меню)
- Создай файл `app/teacher/layout.tsx`.
- Реализуй **постоянно видимое левое боковое меню (Sidebar)**.
- Оно **не должно** скрываться под кнопку "гамбургер" на десктопе.
- В меню должны быть крупные иконки (из `lucide-react`) и четкие текстовые подписи (используя простую терминологию выше).
- Ссылка на "Главную страницу".

### 2. Главная страница (Main Page)
- Создай страницу `app/teacher/page.tsx` (или обнови существующую).
- Это "Отправная точка" (Dashboard).
- На ней должны быть **крупные карточки-плитки (Tiles)** для быстрого перехода к основным действиям:
  - Плитка "Начать урок" (самая большая/акцентная).
  - Плитка "Ученики" (добавить/посмотреть группы).
  - Плитка "Журнал оценок".
  - Плитка "База билетов".
- Плитки должны иметь иконку, заголовок и краткое понятное описание.

## Задачи для выполнения
1. Реализуй `layout.tsx` с боковым меню.
2. Реализуй `page.tsx` с крупными плитками.
3. Настрой глобальные стили (в `globals.css` или Tailwind config), чтобы шрифт по умолчанию был крупнее, а цвета `muted` были более контрастными.
4. Убедись, что тесты в `tests/27_teacher/27_00_layout.test.tsx` проходят.
