# Задача 27.1: Управление группами (Teacher Workspace)

## Контекст
Мы реализуем "Рабочее место Преподавателя" на Next.js (React 19). Бэкенд уже готов.
Раздел: Управление группами (роут `/teacher/groups`).

## Требования к UI
1. **Список групп:** Таблица или карточки с существующими группами (название, профиль, кол-во курсантов).
2. **Создание группы:**
   - Форма с вводом названия группы.
   - Обязательный Dropdown (Select) `profile` со значениями `OPERATOR_112` и `DISPATCHER_DDS`.
3. **Добавление курсантов:**
   - Drag-and-drop зона для загрузки CSV файла.
   - Кнопка загрузки, которая отправляет файл на бэкенд.

## Задачи для выполнения
1. Настрой необходимые зависимости для тестирования (Vitest, React Testing Library), если их еще нет.
2. Реализуй страницу `/teacher/groups`.
3. Используй компоненты из `shadcn/ui` (Table/Card, Select, Button, Input, Dropzone).
4. Запусти тесты из `tests/27_teacher/27_01_groups.test.tsx` и добейся их успешного прохождения.

## API Интеграция (Mock для тестов)
- `GET /api/v1/groups` - получение списка
- `POST /api/v1/groups` - создание
- `POST /api/v1/groups/{id}/students/csv` - загрузка CSV (multipart/form-data)
