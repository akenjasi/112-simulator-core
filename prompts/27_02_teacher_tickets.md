# Задача 27.2: База билетов (Teacher Workspace)

## Контекст
Раздел: База билетов (роут `/teacher/tickets`).
Преподаватель генерирует билеты для занятий с помощью алгоритмического рандомизатора бэкенда.

## Требования к UI
1. **Панель генерации:**
   - Инпут (Input type="number") "Количество" (по умолчанию 50).
   - Кнопка "Сгенерировать пакет".
2. **Список билетов (Дашборд):**
   - Таблица сгенерированных билетов.
   - Поле `complexity` (Сложность 1, 2, 3) должно отображаться визуально (Бейджики: Зеленый, Желтый, Красный).
3. **Действия:**
   - Возможность посмотреть детали билета (модалка или раскрывающийся список).
   - Кнопка "Утвердить пакет".

## Задачи для выполнения
1. Реализуй страницу `/teacher/tickets`.
2. Используй `shadcn/ui` (Badge, Table, Input, Button).
3. Запусти тесты из `tests/27_teacher/27_02_tickets.test.tsx` и добейся их прохождения.

## API Интеграция
- `POST /api/v1/tickets/generate` - `{"count": 50}`
- `GET /api/v1/tickets` - получение списка
