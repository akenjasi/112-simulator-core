# Задача 27.3: Настройка и запуск занятия (Teacher Workspace)

## Контекст
Раздел: Создание занятия (роут `/teacher/sessions/new`).
Преподаватель настраивает параметры сессии перед ее запуском.

## Требования к UI
1. **Форма "Создать занятие":**
   - Выбор Группы (Select).
   - Выбор Категорий (Multi-select: Пожары, Медицина и т.д.).
   - Сложность (RadioGroup: `level_1`, `level_2`, `level_3`, `mixed`).
   - Режим распределения (RadioGroup: `live_stream`, `exam`).
2. **Опциональные настройки:**
   - "Лимит времени (сек)" (Input type="number", placeholder="Автоматически").
   - "Допустимое количество ошибок" (Input type="number", placeholder="Автоматически").
3. **Действие:**
   - Кнопка "Создать и запустить".

## Задачи для выполнения
1. Реализуй страницу `/teacher/sessions/new`.
2. Используй `react-hook-form` для управления состоянием формы.
3. Запусти тесты из `tests/27_teacher/27_03_session.test.tsx`.

## API Интеграция
- `POST /api/v1/sessions` - создание сессии с выбранной конфигурацией.
