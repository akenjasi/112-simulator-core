# Задача 27.4: Мониторинг в реальном времени (Teacher Workspace)

## Контекст
Раздел: Live Dashboard (роут `/teacher/sessions/[id]/live`).
Отображение прогресса курсантов в режиме реального времени.

## Требования к UI
1. **Live Дашборд:**
   - Табличный вид или Grid-сетка со списком курсантов в группе.
   - У каждого курсанта счетчики: "В процессе", "Сдано", "Провалено".
   - Общий прогресс бар сессии.
2. **Ограничения:**
   - Нет кнопок паузы или вмешательства (только чтение/наблюдение).
   - Данные должны обновляться (в идеале через SWR/React Query polling или WebSocket, если бэкенд поддерживает, пока можно просто Polling раз в 3 сек).

## Задачи для выполнения
1. Реализуй страницу `/teacher/sessions/[id]/live`.
2. Сделай polling данных для обновления статусов.
3. Запусти тесты из `tests/27_teacher/27_04_dashboard.test.tsx`.

## API Интеграция
- `GET /api/v1/sessions/{id}/stats` - получение текущей статистики по курсантам.
