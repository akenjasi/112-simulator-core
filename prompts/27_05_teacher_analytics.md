# Задача 27.5: Пост-аналитика и Апелляция (Teacher Workspace)

## Контекст
Раздел: Журнал разбора (роут `/teacher/analytics`).
Оценка результатов прошедшей сессии и ручная коррекция оценок.

## Требования к UI
1. **Детализация по курсантам:**
   - Список курсантов с процентом успеха.
2. **Сплит-скрин карточки (Разделенный экран):**
   - При клике на ответ курсанта открывается окно (две колонки).
   - Левая колонка: Эталон (`etalon`).
   - Правая колонка: Ввод курсанта.
   - Ошибки из массива `error_details` подсвечиваются красным/желтым цветом.
3. **Апелляция:**
   - Кнопка "Изменить оценку".
   - Модальное окно с `Textarea` для комментария преподавателя.
   - Кнопка "Сохранить" (отправляет PATCH запрос).

## Задачи для выполнения
1. Реализуй страницу `/teacher/analytics` и компонент Сплит-скрина.
2. Запусти тесты из `tests/27_teacher/27_05_analytics.test.tsx`.

## API Интеграция
- `GET /api/v1/analytics/sessions/{id}` - статистика сессии.
- `GET /api/v1/analytics/records/{record_id}` - детали конкретного ответа (`etalon`, `student_answer`, `error_details`).
- `PATCH /api/v1/analytics/records/{record_id}/appeal` - `{"status": "passed", "comment": "Опечатка"}`.
