# Задача 27.6: База знаний (Teacher Workspace)

## Контекст
Раздел: База знаний (роут `/teacher/knowledge`).
Загрузка PDF/DOCX файлов регламентов для курсантов.

## Требования к UI
1. **Файловый менеджер:**
   - Список (или Grid) загруженных документов (название, дата загрузки, размер).
2. **Загрузка файлов:**
   - Кнопка "Загрузить документ" (открывает системное окно выбора файла).
   - Поддержка PDF и DOCX.
   - Использование `FormData` для отправки на сервер (`multipart/form-data`).

## Задачи для выполнения
1. Реализуй страницу `/teacher/knowledge`.
2. Запусти тесты из `tests/27_teacher/27_06_knowledge.test.tsx`.

## API Интеграция
- `GET /api/v1/knowledge/files` - список файлов.
- `POST /api/v1/knowledge/files` - загрузка файла.
