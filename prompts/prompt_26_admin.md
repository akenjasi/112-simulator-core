# Задача 26: Инструменты администратора (Healthcheck и Backup)

## Контекст
Администраторам системы требуется мониторинг состояния сервера в реальном времени и возможность делать резервные копии базы данных.

## Что нужно сделать:

1. **Эндпоинт Healthcheck**:
   - В роутере для админов (например, `backend/api/router_users.py` или новый `router_admin.py`) добавь `GET /api/admin/healthcheck`.
   - Добавь библиотеку `psutil` в `requirements.txt`.
   - Эндпоинт должен быть защищен `Depends(require_role("ADMIN"))`.
   - Возвращаемая Pydantic схема должна содержать: `cpu_percent`, `ram_percent` и `db_status` (результат выполнения `SELECT 1` к базе).

2. **Скрипт резервного копирования**:
   - Создай `scripts/backup_db.py` (или `.sh`).
   - Скрипт должен смотреть на `DATABASE_URL` из окружения (или `.env`).
   - Если драйвер `sqlite` (или `aiosqlite`), скрипт должен копировать файл (обычно `data/database.db`) в папку `data/backups/` с добавлением текущего времени в имя файла.
   - Если драйвер `postgresql` (или `asyncpg`), скрипт должен вызывать утилиту `pg_dump` через `subprocess` и сохранять `.sql` дамп в `data/backups/`.
   - Папка `data/backups/` должна создаваться автоматически, если её нет.

3. **Эндпоинт Backup**:
   - Добавь `POST /api/admin/backup`. Защищен для `ADMIN`.
   - Этот эндпоинт должен импортировать логику из `scripts/backup_db.py` (выделить функцию создания бекапа) и выполнять её.
   - Возвращает путь к созданному файлу бекапа и статус.

4. **Проверка**:
   - Я написал `tests/26_test_admin_tools.py`. Убедись, что он проходит (проверяется возврат CPU/RAM и успешный ответ от ручки бекапа).

## Архитектурные требования:
- Вызов `psutil` и `subprocess` в FastAPI должен быть асинхронным, чтобы не заблокировать Event Loop (используй `asyncio.to_thread` или `subprocess.create_subprocess_exec` для `pg_dump`).
