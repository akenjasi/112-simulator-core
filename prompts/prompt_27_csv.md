# ТЗ 27: Парсинг CSV курсантов (Сценарий 1)

**Статус:** Готово к выполнению воркером
**Расположение файлов:**
- `backend/core/csv_parser.py` (Основная логика)
- `backend/schemas/domain_01.py` (Схемы)

## Контекст
Реализуем Сценарий 1 (Управление группами). Преподавателю нужна возможность массово добавлять курсантов через загрузку CSV файла.
Согласно архитектуре "Functional Core", роутер FastAPI только принимает `UploadFile`, а сам парсинг и валидация строк происходит в чистой функции ядра.

## Задачи для воркера

1. **Создать схему Pydantic (в `backend/schemas/domain_01.py`):**
   - `StudentCSVRow`: поля `first_name` (str), `last_name` (str), `email` (str - валидация EmailStr, если используется pydantic.EmailStr, либо простая валидация через regex).

2. **Реализовать чистую функцию `parse_students_csv`:**
   Создать файл `backend/core/csv_parser.py`.
   Реализовать функцию:
   ```python
   from typing import IO
   from backend.schemas.domain_01 import StudentCSVRow

   def parse_students_csv(file_obj: IO[str]) -> list[StudentCSVRow]:
       pass
   ```
   
   **Логика внутри функции:**
   - Использовать стандартную библиотеку `csv` (например, `csv.DictReader`).
   - Проверить наличие обязательных колонок: `first_name`, `last_name`, `email`. Если какой-то колонки нет, выкинуть `ValueError(f"Отсутствуют обязательные колонки: {missing_cols}")`.
   - Прочитать строки, валидировать их через Pydantic схему `StudentCSVRow`.
   - Вернуть список валидированных объектов.
   - Игнорировать пустые строки.

3. **Ограничения:**
   - Функция должна работать с любым файловым объектом (в памяти или на диске), который поддерживает `read()` строк.
