## Контекст
Мы начинаем реализацию модуля "Рабочее место Преподавателя". В этой части мы закладываем фундамент: профили учебных групп и алгоритм расчета сложности билетов, который работает по принципу "Functional Core".

## Задачи для воркера

1. **Добавить Enum для Профилей групп:**
   В файлах `backend/schemas/domain_01.py` (и если необходимо для SQLAlchemy в `backend/models/domain_01.py`) создать строгий Enum `ProfileType`:
   - `OPERATOR_112` (Оператор 112)
   - `DISPATCHER_DDS` (Диспетчер ДДС)
   
   В модели и схеме Группы (`Group`) добавить обязательное поле `profile: ProfileType`.

2. **Реализовать чистую функцию `calculate_complexity`:**
   Создать файл `backend/core/complexity.py`. Написать функцию со следующей сигнатурой:
   ```python
   def calculate_complexity(services_count: int, markers: list[str]) -> int:
       pass
   ```
   
   **Логика работы:**
   - Если `services_count >= 3` ИЛИ в `markers` есть строки (без учета регистра), содержащие `"угроза"` или `"пострадавш"` -> возвращать `3` (Уровень 3).
   - Иначе, если `services_count == 2` ИЛИ в `markers` есть строки, содержащие `"инфраструктур"` или `"перекрыт"` -> возвращать `2` (Уровень 2).
   - В остальных случаях возвращать `1` (Уровень 1).
   - Уровень 3 имеет наивысший приоритет (если есть признаки и 2, и 3 уровня, возвращаем 3).
