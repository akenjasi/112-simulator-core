# ТЗ 01: Изолированный генератор фейковых данных (Faker)

**Статус:** Готово к выполнению воркером
**Расположение файлов:**
- `backend/core/faker.py` (Основная логика)
- `backend/schemas/faker.py` (Pydantic схемы)
- `data/moscow_112_addresses.json` (Уже скопирован, источник адресов)

## Контекст (Правила Архитектуры V2)
В симуляторе 112 (MVP) мы используем алгоритмический "Псевдо-ИИ". Нам нужен модуль `FakeDataGenerator`, который будет детерминированно (по seed) генерировать случайные данные для сценариев: ФИО, роли заявителей, адреса (из реальной базы Москвы), телефоны и автомобильные номера. 
Архитектура требует изолированной логики (Functional Core). 

## Задачи для воркера

1. **Создать схемы Pydantic в `backend/schemas/faker.py`:**
   - `GeneratedPerson`: поля `first_name` (str), `last_name` (str), `middle_name` (str).
   - `GeneratedAddress`: поля `city` (str), `street` (str), `house` (str), `corpus` (str, опционально), `structure` (str, опционально), `full_address` (str), `lat` (float), `lon` (float).

2. **Создать класс `FakeDataGenerator` в `backend/core/faker.py`:**
   - **Инициализация:** `__init__(self, seed: int = None)`. Должен инициализировать собственный экземпляр `random.Random(seed)`, чтобы не ломать глобальный `random` и гарантировать детерминированность. Если seed передан, все методы должны возвращать одни и те же результаты при одинаковом порядке вызова.
   - **Метод `generate_person(self) -> GeneratedPerson`:**
     - НЕ использовать библиотеку `faker` (в ней встречаются слишком устаревшие/странные имена, которые плохо воспринимаются на слух).
     - Внутри файла захардкодить списки из 100-200 самых популярных русских мужских и женских имен, фамилий и отчеств.
     - Случайно выбирать пол, а затем соответствующие ФИО. Возвращать объект `GeneratedPerson`.
   - **Метод `generate_role(self) -> str`:**
     - Возвращать одну из ролей из списка: `["Пострадавший", "Очевидец", "Родственник", "Знакомый", "Сотрудник"]`.
   - **Метод `generate_phone(self) -> str`:**
     - Генерировать мобильный телефон в формате `+79XXXXXXXXX` (строго 12 символов, без пробелов и тире).
   - **Метод `generate_car_plate(self) -> str`:**
     - Использовать следующую логику (адаптировав под локальный экземпляр `random`):
       ```python
       LETTERS = 'АВЕКМНОРСТУХ'
       MOSCOW_REGIONS = ['77', '97', '99', '177', '197', '199', '777', '797', '799']
       # Формат: буква - 3 цифры - 2 буквы - пробел - регион (например: А123ВЕ 77)
       ```
   - **Метод `generate_address(self) -> GeneratedAddress`:**
     - При первом обращении к методу загружать в память (кешировать в атрибут класса) файл `data/moscow_112_addresses.json` (ленивая загрузка/Lazy Load).
     - Случайно (с помощью `self.random.choice`) выбирать один адрес из массива.
     - Возвращать объект `GeneratedAddress`.

3. **Ограничения:**
   - Не добавлять внешние зависимости (кроме pydantic).
   - Код должен строго соответствовать тестам из `tests/test_faker.py`.

## Команда проверки

`pytest tests/test_faker.py -v`
Убедитесь, что все тесты проходят.
