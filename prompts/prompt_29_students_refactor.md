## Контекст (ВАЖНОЕ ИЗМЕНЕНИЕ)
Мы меняем бизнес-логику: **Группы больше не привязываются к профилю (112 или ДДС).** 
Группа — это просто набор людей (смена, поток). Профиль (роль) будет задаваться только в момент создания Занятия (Сессии). 
Также мы расширяем данные ученика (добавляем отчество) и вводим генерацию паролей (5 цифр).

## Задачи для Backend-воркера

1. **Рефакторинг Моделей и Схем (domain_01):**
   - **Удалить** поле `profile` из модели `StudentGroup` и из всех Pydantic-схем, связанных с группами.
   - В схему `StudentCSVRow` и `SingleStudentAddRequest` добавить опциональное поле `middle_name` (str).
   - Шаблон CSV теперь должен быть: `last_name,first_name,middle_name,email`.

2. **Эндпоинты управления паролями:**
   - `POST /api/users/{user_id}/reset-password` -> Генерирует 5 случайных цифр (например, `random.randint(10000, 99999)`), хеширует, сохраняет в БД и возвращает этот пин-код в ответе API (чтобы фронт мог его показать).
   - `POST /api/groups/{group_id}/reset-passwords` -> Проходится по всем ученикам группы, генерирует каждому новый 5-значный пароль, сохраняет и возвращает список объектов `[{"user_id": 1, "fio": "Иванов И.И.", "email": "a@a.com", "new_password": "12345"}]`. Это нужно для функции "Распечатать доступы".

3. **Обновление `seed.py`:**
   - Убрать слово "Курсант" из имен. Сделать нормальные ФИО: "Иванов Иван Иванович", "Петров Петр Петрович".
   - Использовать их `email` в качестве `username` (логина). Например: логин `ivanov@test.com`, пароль `12345`.
   - Группы переименовать просто в "Смена 1" и "Смена 2" (без привязки к 112/ДДС).

## Рекомендации для Frontend-воркера
- **Интерфейс "Все ученики":** Главная таблица, показывающая всех учеников. В колонке "Группа" через запятую выводить группы, в которых состоит ученик (например: "Смена 1, Смена 2").
- **Кнопка сброса пароля:** Возле каждого ученика кнопка "Сбросить пароль", которая открывает модалку с новым 5-значным кодом.
- **Интерфейс "Группы":** Список групп должен быть **сверху** (как самое важное). Форма создания новой группы и загрузка CSV должны быть скрыты под кнопкой "Добавить группу/учеников", которая открывает модальное окно или выезжающую боковую панель (Drawer), чтобы не перекрывать основной список.
- **Печать доступов:** Внутри раскрытой группы кнопка "Сбросить пароли всей группе". После подтверждения API вернет массив паролей, и фронтенд должен сгенерировать печатную форму (например, обычное HTML-окно с `window.print()`), где будет табличка: ФИО - Email - Пароль.
