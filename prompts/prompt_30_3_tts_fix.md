# ТЗ 30.3: Фикс 500 Ошибки TTS (Санитизация Текста)

**Статус:** Готово к выполнению воркером
**Расположение файлов:**
- `backend/core/tts_v2.py`
- `backend/api/router_tickets.py` (опционально, если нужно убрать error.log)

## Контекст (Суть бага)
При попытке сгенерировать аудио билета, в котором телефон начинается с символа `+` (например, `+79443759255`), движок **Silero TTS** выбрасывает `ValueError` в недрах функции `prepare_tts_model_input`. 
Silero TTS поддерживает только кириллицу, цифры и базовую пунктуацию (.,!?-). Любые другие символы (включая `+`, английские буквы, скобки) ломают генерацию аудио, что приводило к ошибке 500 на эндпоинте склеивания аудио.

## Задачи для Backend-воркера

1. **Добавить санитизацию в движок TTS:**
   В файле `backend/core/tts_v2.py` найдите метод `synthesize`. Перед передачей `text_clean` в `self.model.apply_tts()`, добавьте очистку текста с помощью регулярных выражений:
   ```python
   import re
   
   # Заменяем плюс словом, так как это часто телефон
   text_clean = text_clean.replace('+', 'плюс ')
   
   # Вычищаем всё, что не является русской буквой, цифрой или разрешенной пунктуацией
   text_clean = re.sub(r'[^а-яА-ЯёЁ0-9\s.,!?-]', '', text_clean)
   ```
2. **Проверить пустые строки:**
   После `re.sub` строка может оказаться пустой (если она состояла только из английских букв). Если `text_clean.strip() == ""`, функция `synthesize` должна просто возвращать пустой `bytes()` (или перехватить это логикой выше, чтобы не кормить пустую строку в модель).

3. **Очистка временного дебага:**
   В `backend/api/router_tickets.py` в функции `get_ticket_audio` уберите запись `traceback` в `error.log`, которую оставили для отладки, и верните обычный `logger.error` или принты.

Запустите `pytest tests/test_30_tts_fix.py` для проверки регулярки.
