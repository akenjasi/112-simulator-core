# ТЗ 30.1: Патч Бэкенда (Статус генерации)

**Статус:** Готово к выполнению воркером
**Расположение файлов:**
- `backend/api/router_tickets.py` (или где реализован эндпоинт генерации)

## Контекст
Предыдущий воркер уже реализовал эндпоинт генерации билетов (`POST /api/tickets/generate`), который использует `BackgroundTasks`. 
Чтобы фронтенд мог честно показывать статус загрузки, нам нужен эндпоинт, который будет отдавать текущий статус фоновых задач генерации.

## Задачи для воркера

1. **Реализовать эндпоинт `GET /api/tickets/status`:**
   - Если генерация идет в `BackgroundTasks`, FastAPI по умолчанию не отслеживает их статус. 
   - **Решение:** Заведите глобальную переменную (например, `active_generations: int = 0`) в файле роутера или сервиса.
   - При старте `POST /api/tickets/generate` увеличивайте `active_generations += count`.
   - Внутри фоновой функции (после завершения TTS для конкретного билета или всего батча) уменьшайте `active_generations`.
   - Эндпоинт `GET /api/tickets/status` должен возвращать JSON:
     ```json
     {
       "is_generating": true,
       "remaining_tickets": 5
     }
     ```
     (Если `active_generations == 0`, то `is_generating` = false).

2. **Альтернативный вариант (Простой):**
   - Если сложный трекинг сделать тяжело, эндпоинт может просто возвращать `{"is_generating": false}` по умолчанию, а фронтенд пока будет использовать Mock (заглушку) для тестов UI. Но лучше сделать через простейший глобальный счетчик.

Сделай этот небольшой коммит в бэкенд, чтобы фронтенду было к чему стучаться!
