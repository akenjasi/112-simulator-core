# ТЗ 34: Улучшение UI Учеников и Групп

**Статус:** Готово к выполнению (Frontend-воркер)

## 1. Вкладка "Все ученики" (Фильтры и Колонки)
- **Фильтр групп по умолчанию:** При открытии вкладки "Все ученики" в фильтре выбора группы должно стоять "Все" (или пусто), а не выделяться какая-то конкретная группа. Пользователь должен сразу видеть полный список.
- **Колонки ФИО:** Сейчас сервер присылает `full_name` (например, "Петров Александр Владимирович"). Разбейте эту строку на фронтенде и сделайте в таблице три отдельные колонки: **Фамилия**, **Имя**, **Отчество**. Если слов меньше трёх, распределяйте логично.
- **Локализация ролей:** В таблице не должно быть английского слова `CADET`. Отображайте роль на русском — **"Ученик"** (или "Слушатель").
- **Удаление слова "Курсант":** В таблицах и карточках учеников уберите приставку "Курсант", если она где-то хардкодится. Пусть будет просто ФИО.

## 2. Подтверждение сброса паролей
- При нажатии на кнопку **"Сбросить пароль"** для *конкретного (одного)* ученика в таблице, должно появляться **модальное окно с подтверждением** (так же, как это сделано для массового сброса паролей всей группе).
- Пароль по умолчанию после сброса должен состоять из 5 цифр (если бэкенд это уже поддерживает, просто показывайте пароль после сброса, либо передавайте эту логику).

## 3. Страница "Список групп"
- Уберите кнопку **"Выбрать"** напротив каждой группы в таблице. Она вводит в заблуждение, так как пользователи переходят внутрь группы кликом на строку или через кнопку "Детали/Редактировать".
- Сделайте кнопку **"Добавить группу"** более крупной и заметной (например, `size="large"`, акцентный цвет или широкая кнопка сверху списка), чтобы преподавателю было очевидно, как создать новую группу.

Сиды на бэкенде уже обновлены (`seed.py`), там теперь реальные ФИО "Петров Александр Владимирович" вместо "Петров А.В.". Ваша задача — красиво и удобно отобразить их на клиенте.
