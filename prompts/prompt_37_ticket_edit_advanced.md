# ТЗ 37: Продвинутое редактирование билетов и работа с адресом

**Статус:** Готово к выполнению (Frontend)

## 1. Выбор категории и подкатегории из списков
Чтобы не сломать систему проверки карточки, преподаватель не должен вводить категорию и подкатегорию произвольным текстом.
- В модальном окне редактирования билета замените текстовые поля `Категория` и `Подкатегория` на выпадающие списки (Dropdown/Select).
- Используйте новые API-эндпоинты бэкенда:
  - `GET /api/classifier/categories` (возвращает массив строк категорий).
  - `GET /api/classifier/subcategories?category={название_категории}` (возвращает массив строк подкатегорий).
- При смене категории поле "Подкатегория" должно сбрасываться/очищаться.

## 2. Кнопка "Сгенерировать другой адрес"
Ввод улицы и дома вручную сломает геолокацию на карте в симуляторе. Улица и дом должны быть строго из нашей базы.
- Сделайте поля "Улица происшествия" (`ground_truth.street`) и "Дом / строение" (`ground_truth.house`) **только для чтения** (read-only) или заблокированными.
- Добавьте рядом с этими полями кнопку (иконку обновления / кубиков) с подсказкой **"Сгенерировать случайный адрес"**.
- При нажатии делайте запрос к новому API: `GET /api/generator/address`.
- Он вернет JSON-объект: `{ street, house, apartment, floor, entrance, intercom, ... }`. Обновите соответствующие поля в форме редактирования.

## 3. Новые поля: Квартира, Этаж, Подъезд, Домофон
В 112 диспетчер часто спрашивает номер квартиры или этаж, и они должны быть в карточке (Ground Truth).
- Добавьте в форму редактирования абонента 4 новых текстовых поля:
  - Квартира (`ground_truth.apartment`)
  - Этаж (`ground_truth.floor`)
  - Подъезд (`ground_truth.entrance`)
  - Код домофона (`ground_truth.intercom`)
- Эти поля (в отличие от улицы и дома) преподаватель **может** редактировать вручную. Бэкенд уже поддерживает их сохранение.

## 4. Выбор служб из справочника (Services)
- В блоке "Назначенные службы" при добавлении новой службы преподаватель должен выбирать её из выпадающего списка.
- Используйте новый API: `GET /api/classifier/services` (возвращает массив строк всех ~45 доступных служб из БД).
