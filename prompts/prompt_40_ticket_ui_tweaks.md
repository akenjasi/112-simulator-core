# ТЗ 40: Мелкие доработки UI Деталей Билета

**Статус:** Готово к выполнению (Frontend)

В модальном окне "Детали билета" сейчас присутствуют две кнопки "Редактировать" — одна в шапке рядом с крестиком закрытия, а другая внизу (в футере).
- Удалите верхнюю кнопку "Редактировать" из шапки модального окна. Оставьте только ту, что находится в футере.
