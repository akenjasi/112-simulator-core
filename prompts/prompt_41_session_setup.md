# ТЗ 41: Рефакторинг модуля "Запуск урока" (Создание сессии) - Настройка и UI

**Цель:** Реализовать корректное создание "Группового урока" (Lesson/Assignment), исправить UI формы настройки для преподавателя и подготовить базу для адаптивной сложности.

## 1. Бэкенд (FastAPI & SQLAlchemy)
Текущая реализация `/api/v1/sessions` создает `ExamSession` (индивидуальную сессию) вместо групповой. 
Необходимо использовать модель `Assignment` (или добавить новую `Lesson`, если `Assignment` перегружен, но лучше расширить `Assignment`) как сущность "Группового урока".

**Изменения в модели `Assignment` (или `Lesson`):**
- Добавить поле `status` (String): `WAITING` (по умолчанию), `ACTIVE`, `COMPLETED`.
- Добавить поле `target_role` (String): `OPERATOR_112` или `DISPATCHER_DDS`.
- Убедиться, что есть поля: `categories` (JSON - список выбранных категорий/подкатегорий происшествий), `complexity` (String - базовая сложность или "adaptive"), `time_limit_seconds` (Integer), `error_limit` (Integer).

**API Эндпоинты (`backend/api/router_sessions.py` или новый `router_lessons.py`):**
- `POST /api/v1/lessons` (Создание урока): Принимает `group_id`, `target_role`, `categories`, `complexity`, `time_limit_seconds`. Создает запись со статусом `WAITING`.
- Написать юнит-тест `tests/api/test_lessons_setup.py`, проверяющий создание урока со статусом `WAITING` и валидацию полей.

## 2. Фронтенд (Next.js) - `frontend_react/app/teacher/sessions/new/page.tsx`
Переработать форму настройки:
- **Группа и Роль:** 
  - Селект группы по умолчанию пуст (`""`). Пользователь обязан выбрать группу.
  - Добавить селект/радио-кнопки выбора роли для тренировки: "Оператор 112" или "Диспетчер ДДС".
- **Категории происшествий:**
  - Убрать жестко заданные "быстрые кнопки".
  - Сделать компонент `MultiSelect` (или аналогичный из shadcn/ui), который подгружает реальные категории и подкатегории из классификатора `/api/classifier/...`. 
  - По умолчанию список пуст, что означает "Все категории и подкатегории". 
  - *Примечание:* Выбираем только категории *происшествий* (взрывы, ДТП), а не категории *служб*.
- **Уровень сложности:**
  - Карточки: "Базовый" (зеленый), "Средний" (желтый), "Продвинутый" (красный), "Адаптивный / Смешанный" (серый/синий). Убрать слово "Level" и цифры.
  - Убрать текст "0 ошибок" или "1 ошибка". Заменить на общую надпись: "Допустимое количество ошибок рассчитывается на основе сложности".
- **Лимиты времени:**
  - По умолчанию 30 секунд. В плейсхолдере написать "По умолчанию (30 сек)". Убрать дублирующийся текст снизу.
- **Отправка формы:** 
  - При успешном создании перенаправлять преподавателя на `teacher/sessions/[id]/live` (Лобби урока).

## 3. Тестирование (для воркера)
- **Бэкенд:** Запусти `pytest tests/api/test_lessons_setup.py` после реализации API.
- **Фронтенд:** Проверь ручным рендером, что селект группы не имеет дефолтного значения и кнопка submit заблокирована до выбора.

---
**Связь с адаптивной сложностью:** 
Если преподаватель выбрал "Адаптивный / Смешанный", в БД `complexity` сохраняется как `"adaptive"`. Логика распределения на основе статистики курсанта будет реализована на этапе выдачи билетов.
