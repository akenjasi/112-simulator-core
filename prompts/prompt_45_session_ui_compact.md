# ТЗ 45: Компактный и информативный UI настройки урока

**Цель:** Сделать интерфейс настройки запуска урока шире, компактнее по высоте, и добавить информацию о наличии доступных билетов по категориям, чтобы преподаватель понимал, какие билеты он включает в урок.

## 1. Бэкенд (FastAPI) - Подсчет билетов
- Добавить новый эндпоинт `GET /api/v1/tickets/counts` (в `router_tickets.py` или `router_lessons.py`), который агрегирует и возвращает количество сгенерированных билетов (`GeneratedTicket` и `ScenarioTicket`) сгруппированных по категориям и подкатегориям.
- Формат ответа должен быть удобен для фронтенда, например:
  `[{"category": "ДТП", "total": 15, "subcategories": {"ДТП с пострадавшими": 10, "ДТП без пострадавших": 5}}, ...]`

## 2. Фронтенд - Layout и Уровни Сложности (`sessions/new/page.tsx`)
- Сделать контейнер страницы шире (увеличить `max-w-*` или убрать ограничение).
- **Сложность:** Существенно сжать карточки уровней сложности. Убрать из них текстовое описание (desc). Оставить только название (например, "Базовый") и цветное обрамление. Выстроить их компактно в один ряд или сбоку от основных настроек.
- **Кнопка запуска:** Сделать кнопку «Создать и запустить» визуально больше (например, `size="xl"` или увеличить padding/text-size) и более акцентной.
- **Группы:** Убедиться, что пустые группы (в которых 0 учеников) всё равно отображаются в выпадающем списке, но имеют пометку "(0 человек)". Их можно оставить заблокированными для выбора, главное — чтобы преподаватель их видел.

## 3. Фронтенд - Категории и количество билетов
- Переработать компонент выбора категорий в два параллельных вертикальных блока (столбика), чтобы уменьшить прокрутку:
  - **Левый столбик (Категории):** Длинный вертикальный список всех основных категорий.
  - **Правый столбик (Подкатегории):** Изначально можно показывать надпись "Выберите категорию для просмотра подкатегорий". При выборе категории(й) слева, здесь отображается список их подкатегорий.
- **Индикация билетов:** Напротив каждой категории и подкатегории выводить бэйджик с количеством билетов (данные из нового эндпоинта). Например: `ДТП (15)`. Если билетов 0, бэйджик можно делать тусклым (opacity).
- **Сводка:** Перед кнопкой «Создать и запустить» (или рядом с ней) выводить общий счетчик доступных билетов по выбранным настройкам (категории + подкатегории + сложность, если возможно, или просто по категориям), например: *"Будет доступно билетов для розыгрыша: 42"*.

## 4. Тестирование
- Убедись, что верстка не ломается на мобильных экранах, несмотря на два столбика для категорий (возможно, на мобилках они должны становиться друг под другом).
- Проверь работу эндпоинта `GET /api/v1/tickets/counts` (напиши базовый тест в `tests/test_45_ticket_counts.py`).
