# ТЗ 46: Исправление генерации билетов и доработка UI (Иконки, Логика выбора)

**Цель:** Починить баг с отсутствующей таблицей `sys_sequences`, вернуть иконки категориям, поправить логику выбора категорий и скорректировать карточки сложности.

## 1. Бэкенд - Исправление генерации билетов (sys_sequences)
- При пересоздании базы через `seed.py` возникает ошибка `no such table: sys_sequences` во время генерации билетов (`generate_tickets_background_task`). Эта таблица используется для сквозной нумерации билетов, но она не описана в SQLAlchemy `Base.metadata`.
- **Задача:** Добавь описание таблицы `sys_sequences` (колонки: `name` (String, PK), `last_val` (Integer)) в один из файлов моделей (например, `backend/models/domain_02.py` или `base.py`), чтобы `Base.metadata.create_all` автоматически создавал её. Добавь инициализацию дефолтной записи `{'name': 'generated_tickets', 'last_val': 0}` в `seed.py`.

## 2. Фронтенд - Доработка UI создания урока (`sessions/new/page.tsx`)
- **Иконки категорий:** Верни схематичные иконки (из `lucide-react`, например `Flame`, `Car`, `HeartPulse` и т.д.) для основных категорий происшествий, как это было раньше.
- **Уровни сложности:** Переименуй «Адаптивный / Смешанный» просто в «Адаптивный», чтобы текст не вылезал за границы.
- **Пустые группы:** Убедись, что группы с 0 учеников видимы в выпадающем списке, но при их выборе запуск занятия блокируется (форма выдает ошибку валидации).
- **Логика выбора категорий:**
  - По умолчанию должно быть очевидно, что "Выбраны все категории".
  - Как только преподаватель кликает на любую первую конкретную категорию (начинает выбор), состояние "Выбраны все" сбрасывается, и выбирается ТОЛЬКО та категория, на которую он кликнул. 
  - Нельзя запустить урок, если массив выбранных категорий пуст (нужна валидация формы), если только мы не используем специальный флаг "Выбраны все".

## 3. Тестирование
- Запусти генерацию билетов через UI (в "Базе билетов") и убедись, что ошибка 500 исчезла и билеты генерируются.
