# ТЗ 47: Бэкенд для профиля ученика и Демо-режима

**Цель:** Создать API для личного кабинета курсанта (универсальный профиль 112/ДДС) со статистикой (матрица компетенций, ошибки) и эндпоинтом для "Демо-старта".

## 1. Обновление модели User
- В `backend/models/domain_01.py` добавь колонку `avatar_url: Mapped[Optional[str]] = mapped_column(String, nullable=True)` в `class User`. 
- Обнови Pydantic схемы (в `schemas/domain_01.py` и `schemas/users.py`), чтобы они принимали и отдавали `full_name` и `avatar_url`.
- (Внимание: так как мы используем SQLite без миграций, напиши в скрипте инициализации или добавь `ALTER TABLE` через `try/except` при старте приложения, чтобы колонка добавилась, если её нет. Или просто рассчитывай, что мы пересоздадим базу).

## 2. Эндпоинты статистики и профиля
- `GET /api/v1/students/me/stats`:
  - Принимает `?role=OPERATOR_112` или `DISPATCHER_DDS` (чтобы статистика фильтровалась по роли, так как профиль универсальный).
  - Возвращает JSON:
    - Средний балл (за всё время, за неделю, за месяц).
    - Количество пройденных уроков.
    - `competence_matrix`: Массив для RadarChart (розы ветров), например: `[{"category": "ДТП", "score": 85}, {"category": "Пожары", "score": 60}]`. Считается как средний балл по категориям билетов из `TicketResult`.
    - `top_errors`: Массив частых ошибок (можно извлекать из `EvaluationResult.feedback` или просто возвращать заглушку `["Не спросил номер квартиры", "Долго вызывал скорую"]`, если логов пока мало).
- `GET /api/v1/students/me/lessons`:
  - Возвращает историю сессий (`ExamSession`) текущего юзера с привязанными результатами билетов, чтобы фронт мог отрисовать аккордеон истории.

## 3. Эндпоинт Демо-запуска
- `POST /api/v1/sessions/demo`:
  - Принимает тело `{"target_role": "OPERATOR_112"}` (или `DISPATCHER_DDS`).
  - Создает фейковый `Lesson` (или `Assignment`) и `ExamSession` со статусом `ACTIVE`.
  - Берет 1 случайный билет из `GeneratedTicket` (если база пуста, возвращает 404 с просьбой сгенерировать билеты).
  - Возвращает `{"session_id": "...", "ticket_id": "...", "role": "OPERATOR_112", "redirect_url": "/operator?session_id=..."}`.
