# ТЗ 49: Улучшение Личного кабинета курсанта и Стартовая страница

**Цель:** Сделать дашборд ученика максимально практичным (без прокрутки), убрать аватарки, добавить новые метрики (скорость, фатальные ошибки) и создать стартовую страницу (точнее Landing page).

## 1. Стартовая страница (`frontend_react/app/page.tsx`)
- Переделай корневую страницу проекта (`localhost:3000`).
- Сделай минималистичный экран с заголовком "Симулятор 112" и двумя большими кнопками:
  1. **"Вход для преподавателя"** (ведет на `/teacher/sessions` или `/teacher/analytics`).
  2. **"Вход для курсанта"** (ведет на `/student/profile`).

## 2. Бэкенд - Расширение API статистики
В эндпоинте `GET /api/v1/students/me/stats` (и связанных схемах) добавь новые поля:
- `cards_solved`: int (Количество решенных карточек/билетов).
- `average_score_7_days`: float (Средний балл за последние 7 дней).
- `score_trend`: float (Разница в баллах с предыдущим периодом, например `+3.5` или `-1.2`).
- `average_processing_time_seconds`: int (Среднее время обработки карточки).
- `time_trend`: int (Динамика времени, например `-15` (стал быстрее на 15 сек)).
- `service_accuracy_percent`: float (Точность выбора служб — актуально для Оператора 112).
- Измени формат `top_errors`. Теперь это должен быть список объектов: 
  `[{"text": "Описание ошибки", "frequency_percent": 85, "is_fatal": true/false}]`.
- В моковых данных (или сидировании) используй ФИО "Иванов Иван Иванович" и сгенерируй короткий `student_id` в формате `СМ1-12`. Удали всё, что связано с `avatar_url` (и из БД, если нужно, и из схем).

## 3. Фронтенд - Редизайн дашборда (`/student/profile/page.tsx`)
- **Компактная шапка:** Выведи ФИО, короткий ID (например, `ID: СМ1-12`) и переключатель роли (112/ДДС) в одну компактную горизонтальную строку, чтобы сэкономить высоту экрана. Аватарки полностью убрать.
- **Метрики с динамикой:**
  - Убери средний балл за месяц. Оставь "За всё время" и "За 7 дней".
  - Рядом со средним баллом за 7 дней выводи тренд (например, зеленым шрифтом `↑ +3%` или красным `↓ -1%`).
  - Добавь вывод "Решено карточек" и "Среднее время обработки" (также с трендом).
  - Для роли "Оператор 112" выводи метрику "Точность назначения служб" (в %).
- **Матрица компетенций:** Исправь цвет текста во всплывающих подсказках (Tooltip) у RadarChart, чтобы он хорошо читался на темном фоне.
- **Ошибки (Фатальные и Мелкие):**
  - Раздели список ошибок на два визуальных блока: "Фатальные ошибки" и "Мелкие недочеты" (используй поле `is_fatal`).
  - Раскрась фон или прогресс-бар ошибок от **желтого** (редко) до **темно-красного** (часто, 90-100%). Зеленый цвет для ошибок не использовать!
- **Справочные материалы:** Добавь небольшую секцию (или вкладку) "Справочные материалы", где пока просто выведи список-заглушку (например, "Алгоритм опроса при ДТП.pdf", "Памятка по службам.pdf") с иконками документов.
