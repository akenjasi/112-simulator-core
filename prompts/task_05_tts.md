# ТЗ для ИИ-агента: Миграция `tts_v2.py`

**Контекст:**
Это последний модуль из старой папки `v2_engine`. Мы договорились, что озвучка выносится во внешний микросервис (или стороннее API) и вызывается асинхронно по HTTP. 
Сам модуль TTS должен быть независимым: принимать текст и возвращать сырые байты (`bytes`), не взаимодействуя с файловой системой (сохранением займется фоновая таска FastAPI).

**Разрешенные для изменения файлы (создай их):**
1. `backend/core/tts_engine.py`

**ЗАПРЕЩЕНО ИЗМЕНЯТЬ:**
- Файл тестов: `tests/test_tts.py`
- Файлы из прошлых этапов.

**Требования к реализации:**
1. В `backend/core/tts_engine.py` реализуй асинхронную функцию `async def generate_audio(text: str) -> bytes`:
   - Так как реальное API TTS пока не подключено, сделай заглушку.
   - Заглушка должна возвращать фейковые байты, включающие текст для тестов (например, `return b"FAKE_AUDIO_DATA_" + text.encode("utf-8")`).
   - Функция обязательно должна быть `async def`. В будущем здесь будет HTTP-запрос через `httpx.AsyncClient`.

**Проверка:**
Запусти `pytest tests/test_tts.py -v`.
Доложи о результатах.
