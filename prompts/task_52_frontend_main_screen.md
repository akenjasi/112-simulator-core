# ТЗ 52: Frontend — Главный экран (Журнал/Грид Карточек)

**Роль:** Frontend Developer (Next.js, React, TailwindCSS, shadcn/ui)
**Контекст:** Разработка симулятора системы 112. Мы параллелим работу фронтенда. Твоя задача — сверстать Главный экран (Журнал происшествий) точь-в-точь как на предоставленном скриншоте.

## Твоя цель: Pixel-perfect верстка Главного экрана (Рабочего стола ПОВ-112)
Создай или обнови компонент/страницу, отвечающую за Журнал (например, `frontend_react/app/operator/journal/page.tsx`).

Опирайся **исключительно на скриншот**, который тебе прикрепили. В интерфейсе должна быть плотная, строгая верстка, характерная для профессиональных диспетчерских систем. Цветовая гамма — темно-серые тона.

### Требования к UI блокам:
1. **Верхний блок поиска:** 
   - Заголовок "Поиск происшествий", длинная строка поиска с лупой, кнопка "сбросить". 
   - Ссылка "расширенный по параметрам" со стрелочкой.
2. **Шапка (Header, правая часть):**
   - Текст: "Понедельник, 17 Февраль 2025".
   - Инфо об операторе (оп. 227, АРМ 007) с иконками наушников ("Подключение: Перейти в перерыв").
   - **Крупные часы:** формата `10:22:52`.
   - **Большая оранжевая кнопка:** "создать новую карточку".
3. **Панель навигации (иконки):**
   - Темно-синяя/серая полоса с квадратными кнопками: `журнал`, `экран`, `статистика`, `УЕР`, `БДЛН`, `вики`, `заявители`, `техника`, `аудит`, `отчеты`, `контроль`, `смена`, `регионы`.
   - Ниже тумблеры (свитчи): `уведомления`, `автообновление` (включен синим), `обращения в очереди`.
4. **Таблица "Список происшествий" (Грид):**
   - **Колонки:** стрелка раскрытия, Связи (скрепка), ЧС (молния), Таймер (часы), Опер., АРМ, Номер, Дата, Время, Тип происшествия, Постр., Статус, Адрес, Проверена (чекбоксы/иконки урны).
   - **Строки:** Темно-серый фон (`#4a5568` или похожий), белый/светлый текст.
   - **Раскрывающаяся часть строки:** Под основной строкой отображается "Описание: " и текст комментария диспетчера.
   - **Данные для мока:** Заполни таблицу хардкодом точно как на скриншоте (Ошибочно набран номер, Справка-103, Дополнительный звонок от заявителя).
   - **Индикаторы:** Реализуй розовую/красную иконку скрепки (как в строке 10:20:51).
5. **Футер таблицы:** Кнопка "выберите группу", пагинация "Страница 1 Записей на странице: 10 1-10 из 23030 < >".

## Технические детали
- Используй `TailwindCSS`. Старайся использовать `flex` и `grid` для плотной компоновки.
- Не подключай реальный бекенд, задача — **исключительно верстка и UI/UX (моки)**.
- Используй `lucide-react` для иконок (или аналоги), подбирая максимально похожие.

Приступай! Твоя задача — сделать экран так, чтобы он был неотличим от скриншота!
