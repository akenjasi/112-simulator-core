# ТЗ 56: Frontend — Модалка "Добавьте службы" и Авто-расчет

**Роль:** Frontend Developer (React/Next.js, TailwindCSS)
**Контекст:** Разработка Симулятора 112. Мы совершенствуем процесс добавления экстренных служб в карточку. Заказчик предоставил скрины реального окна выбора служб и точный список необходимых организаций.

## Задача 1: Верстка модального окна "Добавьте службы"
В файле `frontend_react/app/operator/page.tsx` (или вынеси в отдельный компонент) найди рендер `activeModal === "add_service"`.
Переделай его **строго** под предоставленные скриншоты:
1. **Заголовок:** Крупный, по центру (или слева, как на скрине) "Добавьте службы", справа крестик.
2. **Поиск:** Поле `input` с плейсхолдером "Поиск ...", только нижняя граница (border-bottom), без рамки вокруг (или очень легкая).
3. **Список:** Вертикальный список (не сетка!). Каждая служба занимает всю ширину строки, между ними тонкая серая линия (`divide-y`). 
   - Служба должна выбираться кликом по строке (выделяется цветом/галочкой).
4. **Кнопка:** Внизу по центру кнопка "Сохранить и закрыть". У неё белый фон, оранжевая рамка (`border-[#ec653b]`) и оранжевый текст, при наведении немного меняет фон.

## Задача 3: Автоматический расчет служб (Интеграция с ЕКП)
Сейчас службы можно добавить только вручную. Нам нужна магия!
В `page.tsx` есть колбэк от классификатора, либо сам классификатор (`IncidentClassifier.tsx`) знает о выбранных тегах. 
**Требование:** 
Когда оператор выбирает категорию происшествия или нажимает конечную кнопку в `IncidentClassifier`, фронтенд должен делать POST-запрос на `POST /api/v1/classifier/calculate` (передавая выбранные теги или `final_type`). Бэкенд вернет массив строк (названий служб, например `["101", "ЦОДД"]`). 
Эти службы должны **автоматически** добавляться в массив `services` в `page.tsx` (и отображаться в нижней панели).

*Подсказка:* Для MVP можешь пока сделать фейковый таймаут или эмулировать этот расчет прямо на фронте, если бэкенд `/calculate` требует сложных ID. Если вызываешь бэкенд - убедись, что не ломаешь рендер. Главное — чтобы при заполнении формы ЕКП службы "сами" прыгали в нижнюю панель!
