# ТЗ 57: Frontend — Багфиксы (Логика служб, Таймер, LocalStorage, Верстка)

**Роль:** Frontend Developer (React/Next.js)
**Контекст:** Разработка Симулятора 112. После внедрения ТЗ 56 были обнаружены логические ошибки, недочеты в верстке и сброс состояния при обновлении страницы. Нужно срочно исправить эти баги. Работай с `frontend_react/app/operator/page.tsx` и `IncidentClassifier.tsx` (или связанными компонентами).

## Задача 1: Исправление нелогичных авто-служб и сброса
1. **Баг с нелогичными службами:** Когда выбираешь происшествие (например, "Отмена вызова"), фронтенд почему-то автоматически добавляет саму "Отмену вызова" как службу и приплетает "101". 
   - **Решение:** Проверь логику в `IncidentClassifier.tsx` или в моке авто-расчета (`handleAutoAddServices`). "Отмена вызова" (или другие не-ЧС типы) не должны триггерить вызов "101".
2. **Очистка служб при отмене происшествия:** Если оператор нажимает крестик (X) сброса типа происшествия в правом блоке, то `incidentType` становится `null`. В этот момент массив назначенных служб (`services`) в `page.tsx` должен **очищаться** (или, как минимум, из него должны удаляться службы, которые были добавлены автоматически). Сделай так, чтобы при сбросе типа происшествия, службы сбрасывались.

## Задача 2: Добавление службы "102"
- В модалке "Добавьте службы" (`add_service`) почему-то отсутствует полиция (Служба 102).
- **Решение:** Добавь в хардкодный список (или проверь, что он есть в массиве): `"Служба 102 (Дежурная часть ГУ МВД)"`.

## Задача 3: Персистентность состояния (LocalStorage)
- **Баг:** При обновлении страницы (F5) слетают все заполненные поля адреса, ФИО заявителя и выбранные службы.
- **Решение:** Реализуй сохранение состояния (в `localStorage` или `sessionStorage`) по ключу, например, `operator_state_${ticketId || 'demo'}`. 
- Сохраняй: `callerName`, `address`, `incidentDescription`, `services`, `activeIncidentTitle`, `classifierAggregatedText` и прочие важные стейты. 
- При монтировании компонента (`useEffect`) восстанавливай эти данные, если они есть.

## Задача 4: Таймер
- **Баг:** Секунды постоянно начинаются с 16-ти (из-за старого мока).
- **Решение:** Измени начальное состояние `elapsedSeconds` на `0` (или восстанавливай из `localStorage` вместе с остальным стейтом, если хочешь, чтобы при F5 таймер не сбрасывался).

## Задача 5: Перекрытие верстки (Training Strip)
- **Баг:** Темно-синяя верхняя плашка "Учебный режим: Оператор 112" перегораживает/наползает на основную часть карточки (или выдавливает нижнюю панель за пределы экрана так, что её не видно, либо перекрывает `TopBar`).
- **Решение:** Проверь классы Flexbox на основном контейнере `page.tsx`. Убедись, что:
  - Обертка имеет `h-screen w-full flex flex-col overflow-hidden`.
  - Плашка учебного режима имеет `shrink-0`.
  - Панель `OperatorTopBar` тоже имеет `shrink-0`.
  - Обертка с двумя колонками (Grid) имеет `flex-1 min-h-0 overflow-hidden`.
  - Нижняя панель `OperatorBottomBar` имеет `shrink-0`.
  Ничто не должно быть `position: absolute` или `fixed` так, чтобы оно перекрывало поток (кроме модальных окон).
