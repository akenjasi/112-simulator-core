# ТЗ 62: Архитектура VoIP и Телефонии (Подготовка)

**Роль:** Fullstack Developer
**Контекст:** В будущем мы планируем подключить к тренажеру реальные физические IP-телефоны (например, РТУ Т16Р) по протоколу SIP. Сейчас телефонов в наличии нет, но мы должны заложить правильный стек и абстракции на бэкенде и фронтенде, чтобы потом интеграция заняла минимум времени.

## Выбранный стек (Free & Open Source):
- **PBX (АТС):** Asterisk (будет поднят в Docker). Бесплатная, индустриальный стандарт.
- **Интеграция с Python:** `panoramisk` (для AMI) или `ari-py` (Asterisk REST Interface).
- **Фронтенд (WebRTC):** `sip.js` (бесплатная JS-библиотека для звонков прямо в браузере как fallback, если физического телефона нет).

## Задача 1: Создание абстракции телефонии (Backend)
1. Создай файл `backend/api/router_telephony.py`.
2. Реализуй заглушки (mock) для эндпоинтов, которыми мы будем управлять АТС:
   - `POST /api/v2/telephony/start_call` (принимает `ticket_id`, `operator_ext` - внутренний номер). 
   - `POST /api/v2/telephony/hangup`
   - `POST /api/v2/telephony/play_audio`
3. Внутри этих эндпоинтов напиши комментарии (TODO), что здесь будут вызовы к Asterisk REST API (ARI).
4. Сейчас (для MVP) эти эндпоинты должны просто имитировать задержку (1 сек) и менять стейт сессии в базе (например, статус звонка `RINGING` -> `ANSWERED`), а также отправлять событие по WebSocket на фронтенд.

## Задача 2: Обновление логики фронтенда (React)
Сейчас таймер и звонок "начинаются" просто по факту загрузки страницы. Это неправильно.
1. Установи библиотеку `sip.js` в `frontend_react` (`npm install sip.js`), чтобы в `package.json` уже была зависимость. Пока не пиши сложную логику регистрации, просто сделай пустой хук `useTelephony`.
2. Фронтенд должен слушать WebSocket от бэкенда (или поллить статус сессии).
3. **Логика:**
   - Когда сессия в статусе `RINGING`, на экране (или в TopBar) показывается имитация входящего звонка (гудки).
   - Когда бэкенд шлет сигнал `ANSWERED` (имитируя, что оператор снял трубку на столе), на фронтенде **только в этот момент** стартует таймер `elapsedSeconds` (начинается с 0).
   - При нажатии на красную кнопку "Положить трубку" в интерфейсе, фронтенд должен делать вызов к `POST /api/v2/telephony/hangup`.

Таким образом, мы отвязываем UI карточки от физического источника звука. Бэкенд управляет АТС, АТС шлет сигналы, фронтенд их отображает.
