# ТЗ: Отказоустойчивость WebSockets (Frontend)
**Роль:** Frontend Developer

## Контекст
По требованию ТЗ, система должна обеспечивать «работоспособность при кратковременных сбоях сети (до 30 секунд) с автоматическим восстановлением сессий без потери данных».
В данный момент, если во время звонка (сессии) моргнет интернет, WebSocket соединение разрывается и сессия крашится.

## Задачи:
1. Открыть Zustand-стор `frontend_react/store/useCallStore.ts` (или аналогичный, где управляется WebSocket звонка).
2. Настроить обработчик `ws.onclose`:
   - Если статус сессии всё еще активен (не было ручного завершения), попытаться выполнить переподключение (Exponential Backoff или каждые 3 секунды в течение 30 секунд).
3. При успешном реконнекте возобновлять отправку/прием аудио.
4. Вывести на UI (на экране звонка) плашку: "Соединение потеряно, переподключение..." при падении WS.
5. Проверить (заглушками) тесты в `frontend_react/tests/websocket_resilience.test.ts`.

## Ограничения
- Сохранять состояние диалога (массив сообщений) при обрыве, чтобы после реконнекта оператор видел всю историю.
