# ТЗ: Продвинутая аналитика и Дамми-данные
**Роль:** Fullstack Developer

## Контекст
Нам нужны красивые дашборды (тепловые карты, динамика) и много данных для демонстрации экспорта (Excel/PDF) на демо-стенде.

## Задачи:
1. **Backend & DB Seeding (`backend/database.py` или скрипт `scripts/seed.py`):**
   - Написать логику генерации 50+ учеников, распределенных по 3-5 группам.
   - Сгенерировать для них по 10-20 `TicketResult` (пройденных сессий) в разные даты (за последний месяц) с разными типами ошибок (ошибки коммуникации, карточки, SLA).
   - Расширить `/api/analytics` для выдачи данных, сгруппированных по дням (для графиков) и по типам ошибок (для тепловой карты).
2. **Frontend (`frontend_react/app/teacher/analytics/page.tsx`):**
   - Установить `recharts` в `package.json`.
   - На вкладке аналитики создать 3 графика:
     - **Line Chart:** Динамика среднего балла (за неделю/месяц).
     - **Bar Chart:** Сравнение успеваемости между группами.
     - **Heatmap (или кастомная таблица с цветовым градиентом):** Частота конкретных ошибок у конкретных учеников или групп.
3. Пройти тесты в `tests/test_75_analytics.py`.
