# ТЗ: Пакетный импорт сценариев и билетов
**Роль:** Fullstack Developer

## Контекст
Преподавателю нужно массово загружать билеты. Нужен скачиваемый Excel-шаблон и механизм его загрузки.

## Задачи:
1. **Backend (`backend/api/router_tickets.py`):**
   - Добавить `openpyxl` логику чтения загруженного файла.
   - Эндпоинт `GET /api/tickets/import/template`: генерирует и отдает `.xlsx` файл с колонками (Название, Описание, Номер звонящего, Текст абонента, Целевая служба (01, 02), Обязательные фактоиды (через запятую)).
   - Эндпоинт `POST /api/tickets/import/upload`: принимает `UploadFile`, парсит строки, валидирует данные, создает записи `ScenarioTicket` в БД.
2. **Frontend (`frontend_react/app/teacher/tickets/page.tsx`):**
   - Сделать кнопку "Импорт из Excel". 
   - При нажатии открывается модалка:
     1) Кнопка "1. Скачать шаблон".
     2) Drag & Drop зона "2. Загрузить заполненный файл".
   - Выводить результаты парсинга (успешно: 15, ошибки: 2 (строка 4 пустая целевая служба)).
