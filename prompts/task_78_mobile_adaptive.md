# ТЗ: Адаптивный интерфейс (Mobile UX)
**Роль:** Frontend Developer

## Контекст
Интерфейсы Преподавателя и Администратора должны корректно отображаться на мобильных телефонах (для работы по локальной Wi-Fi сети). Экран Оператора (ученика) НЕ трогаем (остается десктопным).

## Задачи:
1. **Сайдбары (`AdminLayout`, `TeacherLayout`):**
   - Сделать боковое меню скрываемым на мобилках (`md:hidden`).
   - Добавить "гамбургер-меню" в шапке для открытия навигации.
2. **Таблицы (Пользователи, Сессии):**
   - Для узких экранов добавить `overflow-x-auto`, чтобы таблицы скроллились горизонтально, или перестроить их в карточки.
3. **Графики и дашборды:**
   - Настроить ширину графиков `width="100%"` (ResponsiveContainer в recharts).
4. Запустить проект и проверить через Chrome DevTools (размер iPhone) роуты `/admin` и `/teacher`.
