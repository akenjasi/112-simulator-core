# ТЗ: Защита трафика (TLS/HTTPS) на уровне Nginx
**Роль:** DevOps Engineer

## Контекст
В документации заявлено, что для полного соответствия требованиям ИБ нам осталось "активировать поддержку TLS/HTTPS (SSL сертификаты) на уровне входящего прокси-сервера (Nginx) для защиты трафика внутри локальной сети".

## Специфика текущей архитектуры
Текущий Nginx интегрирован прямо в контейнер `frontend` (см. `Dockerfile.frontend` и `docker/nginx.conf`). Этот контейнер отдает статику React и проксирует `/api/` на `backend:8000`. Сейчас он работает только по HTTP (внутри контейнера открыт порт 3000/80).

## Задачи:
1. **Скрипт генерации сертификатов (`scripts/generate_certs.sh`):**
   - Напишите bash-скрипт, который генерирует самоподписанный SSL-сертификат (RSA 2048, 365 дней) в папку `certs/` в корне проекта (файлы `server.crt` и `server.key`). Скрипт должен создавать папку, если ее нет, и выводить сообщение об успехе.
2. **Настройка Nginx (`docker/nginx.conf`):**
   - Настройте сервер на прослушивание порта `443 ssl` (или 8443, главное - SSL).
   - Оставьте прослушивание старого порта (3000 или 80, как было) и сделайте на нем редирект (301) на HTTPS-версию (либо просто оставьте оба, если нужно, но лучше редирект).
   - Укажите пути к сертификатам (например, `/etc/nginx/ssl/server.crt`).
   - Настройте строгие параметры TLS (поддержка только TLSv1.2 и TLSv1.3, современные шифры).
3. **Обновление `docker-compose.yml` и `Dockerfile.frontend`:**
   - В сервисе `frontend` прокиньте порт `443:443` (или тот порт SSL, который вы задали в Nginx).
   - Примонтируйте локальную папку `./certs` в контейнер `frontend` (например, `- ./certs:/etc/nginx/ssl:ro`).
   - Обновите `EXPOSE` в `Dockerfile.frontend`, если меняете порты.
4. **Документация:**
   - В `DOCKER.md` добавьте инструкцию в раздел ИБ: как сгенерировать самоподписанный сертификат для тестов с помощью `generate_certs.sh`, и как подложить корпоративные (боевые) сертификаты для продакшена в папку `certs/`.
5. Проверьте, чтобы тест `tests/test_81_nginx_ssl.py` проходил (он проверяет проброс порта `443` в `docker-compose.yml`).

## Ограничения
- Не сломайте проксирование `/api/` и `/docs` на бэкенд в `nginx.conf`.
