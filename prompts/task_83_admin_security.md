# ТЗ: Функции безопасности администратора и Отчеты о сбоях
**Роль:** Fullstack Developer

## Контекст
В аудите выявлено два недостатка для Администратора:
1. Политики безопасности (срок жизни токена, длина пароля, обязательная 2FA) задаются только через `.env`. Нужен графический интерфейс для их изменения.
2. В интерфейсе нет кнопки «Сгенерировать PDF-отчет о сбоях» (ошибках сервера).

## Задачи:
1. **Динамические политики безопасности (Бэкенд + БД):**
   - Создать таблицу `SystemSettings` (или `SecurityPolicy`) в `backend/models/domain_01.py` с полями `key` (string, unique) и `value` (string).
   - Создать эндпоинты `GET /api/admin/security-policies` и `PUT /api/admin/security-policies` для чтения и массового обновления настроек.
   - Базовые ключи: `MIN_PASSWORD_LENGTH` (по умолчанию 8), `SESSION_TIMEOUT_MINUTES` (по умолчанию 60), `REQUIRE_2FA_ALL` (по умолчанию false).
   - Обновить логику `router_auth.py` (или `security.py`), чтобы длина пароля и таймаут токена брались из БД (с кэшированием или прямым запросом), а не только из хардкода.
2. **Отчет об ошибках в PDF (Бэкенд):**
   - Добавить библиотеку `reportlab` в `requirements.txt`.
   - Настроить глобальный обработчик исключений (exception handler) в `main.py`, который будет писать возникающие 500-е ошибки (traceback) в новую таблицу БД `SystemErrorLog` (поля: `id`, `timestamp`, `error_message`, `traceback`).
   - Создать эндпоинт `GET /api/admin/error-report/pdf`, который с помощью `reportlab` формирует красивый PDF со списком последних 100 сбоев из таблицы `SystemErrorLog` и возвращает его как файл.
3. **Панель Администратора (Фронтенд):**
   - В `frontend_react/app/admin/` создать новую страницу `security` (Политики ИБ).
   - Вывести форму для редактирования 3-х настроек (Длина пароля, Таймаут сессии, Принудительная 2FA).
   - На этой же странице (или на странице "Система") добавить большую кнопку "Скачать отчет о сбоях (PDF)".
4. **Интеграция с Sentry (Опционально/Документация):**
   - Добавить `sentry-sdk` в `requirements.txt`. В `main.py` добавить инициализацию `sentry_sdk.init(dsn=os.getenv("SENTRY_DSN"))`, если DSN задан.
5. **Тестирование:**
   - Обеспечить прохождение заглушечных тестов `tests/test_83_admin_security.py`.
