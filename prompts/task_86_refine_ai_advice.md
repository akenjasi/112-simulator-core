# ТЗ: Перегенерация ИИ-оценок и советов (Refine AI Advice)
**Роль:** Backend API Engineer

## Контекст
Мы ошибочно привязали функцию "Refine Prompt" (перегенерацию по комментарию) к генерации самих билетов. На самом деле ИИ используется только для **оценки успеваемости и советов** (таблицы `AIStudentAdvice` и `AIGroupAdvice`, добавленные в `router_ai_analytics.py`).
Если преподаватель видит, что ИИ дал неправильный совет студенту, он должен иметь возможность отправить текстовый комментарий (например: "ИИ, ты не прав, студент молодец, потому что..."), чтобы ИИ перегенерировал свой вывод.

## Задачи:
1. **API (`backend/api/router_ai_analytics.py`):**
   - Добавить Pydantic-схему `AIRefineRequest` с полем `correction_comment: str`.
   - Создать эндпоинт `POST /api/ai-analytics/student/{advice_id}/refine`.
   - Внутри эндпоинта находить запись в `AIStudentAdvice`.
   - Имитировать вызов LLM (через `await asyncio.sleep(2)`), который якобы переделывает анализ с учетом `correction_comment`.
   - Обновить поле `analysis_text` (например, добавить в начало строку `[Перегенерировано ИИ с учетом: {correction_comment}]\n`), сохранить в БД и вернуть обновленный объект.
2. Убедиться, что `tests/test_86_refine_ai_advice.py` проходит (напишите полноценный тест, создающий запись `AIStudentAdvice` и вызывающий этот эндпоинт).

## Ограничения
- Не затрагивать генерацию билетов (это детерминированный процесс без ИИ).
